# Historical and withdrawn SpinMe builds

This directory intentionally uses the existing repository name `old_bulids/`.

Files here are retained for provenance and historical comparison. They are **not** the current supported release.

## v0.2.0

`SpinMe-v0.2.0-BROKEN.apk` is the withdrawn malformed public v0.2.0 artifact.

Do not distribute or install it as the current release.

The supported replacement is:

`../releases/SpinMe-v1.0.0.apk`

## v0.1.0

The original v0.1.0 APK and its release metadata/checksum are retained for historical purposes.

v0.1.0 used a different Android signing certificate from the current release lineage. An installed v0.1.0 cannot be upgraded in place to v1.0.0; uninstall v0.1.0 before installing the current release.
