# SpinMe demo

SpinMe is created by **Background Gremlin Group — Creating Unique Tools for Unique Individuals**.

The current public release is **v1.0.0**.

The product demo sequence is:

```text
startup → normal spin → acceleration → fast spin → controlled slowdown → branded end card
```

The demo should demonstrate the same core behavior as the release application:

- source animation timing remains independent of RPM;
- ramp-up accelerates spin without retiming the source;
- spin pause leaves animated-source playback running;
- direction changes affect rotation only;
- the full-bleed spiral identity and current carbon/inlay visual treatment are preserved.

Demo media is maintained separately from the source release so the public repository remains source- and binary-release focused.
